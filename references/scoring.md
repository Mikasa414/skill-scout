# 候选评价

默认使用“主推 / 备选 / 暂不推荐”和具体理由，不以精确分数掩盖证据不足。

| 维度 | 检查依据 |
|---|---|
| 任务匹配 | 输入、输出和适用场景是否一致 |
| 增量能力 | 是否补足已有技能、插件或工具的具体缺口 |
| 使用成本 | 依赖、账户、费用、操作系统与维护成本 |
| 质量与维护 | 正文是否可执行，引用是否齐全，依赖是否明确；有证据再谈维护状态 |
| 中文交付 | 能否按要求交付中文；英文说明本身不是缺陷 |

## 证据程度

- 仅描述筛选：用途可能匹配，不能证明质量和可用性。
- 已读正文与依赖：说明检查范围与未知部分，不能据此声称运行成功。
- 已验证：列实际检查、输入范围和结果；格式验证与功能实测分开报告。

用户需要推荐指数时，可按匹配 40、增量能力 25、使用成本 15、质量维护 10、中文交付 10 给参考分，注明为主观匹配判断、非成功率。只在同一任务内比较；缺少证据标记未知，不编造记录。

同领域候选只有在缺少增量或增加不必要成本时降低推荐。不能满足关键要求时直接解释，不用机械分数阈值隐藏原因。
