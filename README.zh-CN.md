# Skill Scout · 技能侦察兵

### 把一句模糊的任务，变成你看得懂、选得明白的技能工作流。

[English](README.md) · [完整示例](examples/interview-to-report.md) · [定制指南](CUSTOMIZING.md)

**先完善需求，再编号推荐；你选好后，说明每一步怎么用技能，确认后执行。**

流程：提出任务 → 关键问题 → 编号推荐 → 选择技能 → 工作流与技能用法 → 确认 → 执行与验证。

## 它能帮你什么

- 最多一次三个关键问题，不重复问上下文已有的信息。
- 先检查当前技能、插件和工具，避免重复安装。
- 每个候选都有序号、理由、来源、安装状态与验证程度。
- 每个复杂步骤可配置多个互补技能，同一技能可跨步骤复用。
- 工作流交代每一步的输入、输出、技能作用和最终验收标准。
- 区分“看过描述”“检查过正文”“实际测试过”，不把匹配判断当成功保证。

## 三个例外

1. 简单明确的任务直接做，不强行选技能。
2. 复杂任务走完整流程，只问关键问题；每个能力面通常推荐两到三个候选，只有一个合适时不凑数。
3. 明确说“你选，直接做”，就在授权范围内跳过选择与工作流确认。

## 快速开始

在 Codex 中说：

```text
$skill-installer 从 https://github.com/Mikasa414/skill-scout 安装技能，技能位于仓库根目录。
```

手动安装命令见 [英文首页](README.md#install-in-codex)。当前官方文档列出用户级 `~/.agents/skills/`；原始本机环境使用 `~/.codex/skills/`。按你实际使用的宿主位置安装，避免重复副本。未发现技能时重启 Codex。

安装后尝试：

```text
$skill-scout 帮我把十份访谈整理成分析报告和汇报 PPT。先问关键问题，再给编号技能选项，选好后说明工作流，等我确认执行。
```

想快速执行时：

```text
$skill-scout 这个任务你选技能，直接做，只使用已安装的技能。
```

## 示例效果

你要做“访谈分析＋报告＋PPT”，它可以推荐：

| 序号 | 能力角色 | 如何参与 |
|---|---|---|
| 1 | 表格技能 | 整理证据、统计问题出现情况、制作图表 |
| 2 | 文档技能 | 将结论与原话依据编排成报告 |
| 3 | 演示技能 | 将关键发现制作成汇报 PPT |

这是角色示意，实际候选需要根据本地安装与可核实来源确定。你选择后，它会解释这些技能如何衔接，列出交付物，再询问是否执行。

## 适合 Fork 的地方

可以改成你的研究助手、产品调研助手、教学备课助手或开发任务助手。优先定制提问、技能评价和步骤交接；保留来源核实与授权边界。见 [定制指南](CUSTOMIZING.md)。

本项目是指令型技能，没有捆绑脚本、API Key 或第三方依赖。它调用宿主已有工具，不自带转写、Office 制作能力或搜索后端。技能正文目前为中文，跨宿主兼容性未独立验证。

已做格式与本地引用检查；未完成外部检索、第三方安装和完整任务执行的端到端实测。示例为模拟对话。
