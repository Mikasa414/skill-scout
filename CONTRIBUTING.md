# Contributing

Useful contributions solve a demonstrated discovery or workflow problem.

- Report a reproducible mismatch: task, host, available skills, expected behavior, observed behavior. Remove personal data and credentials.
- Improve a discovery path with a current source and a tested example.
- Add a domain variant or bilingual example that shows questions, numbered choices, skill handoffs, and confirmation.
- Propose an English instruction variant with behavioral checks. The current core instructions are Chinese.

For a pull request, explain the concrete behavior change and what you actually checked. Validate YAML frontmatter, local Markdown links, and the name/folder relationship. If your host includes `skill-creator`, use its format validator too.

Do not add fabricated usage metrics, unverified compatibility claims, copied proprietary skills, or automation that installs or runs third-party code without authorization.

Contributions are offered under this repository's MIT license. Preserve attribution for any third-party material and confirm its license before including it.
